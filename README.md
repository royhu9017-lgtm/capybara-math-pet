# 咕姆 · 卡皮巴拉数学打卡宠物

投喂孩子每天的数学作业照片，逐题批改、知识点错因归类、结算经验、宠物进化、生成日报与周报。

## 一键安装（复制这句到 WorkBuddy 对话框）

```
帮我安装这个 skill：https://github.com/royhu9017-lgtm/capybara-math-pet
```

装好后新开一个会话，直接说 **「喂卡皮巴拉」** 并附上作业照片即可。

## 首次使用，它会问三件事

1. 宠物叫什么（不答默认「咕姆」）
2. 现在在做什么数学（公文式第几级 / 几年级 / 哪本教辅）
3. 每天几道题（默认 10 题）

答完存档，之后每晚发照片说「喂卡皮巴拉」就行。**建议跑满 7 天再让它出周报**，样本不够它不会出。

## 三条底线

- **不猜**：题目或字迹看不清，一律标「待确认」，不判分、不进错题库，等家长确认后补记
- **不说空话**：反馈必须落到具体题号，比如「第 6 题你只差一步：通分后分子忘了乘」
- **错题不是扣分**：错题记 0 分不倒扣，订正追回 50% 经验——交出错题比蒙对更划算
